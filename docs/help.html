Package Editor Manual

A no-code tool for managing UNQ Kitchen's event packages — edit items, sections, pricing, terms, the venue page, and the visual design — then export a ready-to-publish package/index.html.

Edit → Publish workflow

The editor and the live package page are two separate things. Edits you make in the editor do not automatically appear on the website. You must export and replace the file. Here is the complete flow from opening the editor to seeing changes live:

1
Open the editor

Double-click menu-editor/index.html. It opens in your browser. All previous edits are restored automatically from browser storage.

2
Make your edits

Use any tab — add items, update terms, rename sections, adjust the design. Every change is saved to browser storage as you type. Nothing is lost if you close the tab.

3
Click Export Package Page

Two files download automatically to your Downloads folder:

  • data.json — updated source data
  • package-index.html — the fully styled, ready-to-publish package page
4
Replace the files on disk

Copy both files from Downloads into the site folder:

Downloads/
  data.json             → copy to →  unq-kitchen-site/menu-editor/data.json
  package-index.html  → rename & copy to →  unq-kitchen-site/package/index.html
Rename package-index.html to index.html before placing it in the package/ folder. The site expects the file to be named index.html.
5
Changes are live

Open package/index.html in your browser — you will see all your edits with the full original design intact. Push to GitHub to make it live on the website.

What the exported file contains

The exported package-index.html is a complete, self-contained HTML file. It includes:

  • The full original CSS — all fonts (including the embedded BlippoMN font), colors, layout, print styles
  • Any design changes you made in the Design tab
  • All 9 package pages generated from your current data
  • The Venue & Services (Book Your Space) page as the last page
  • Correct page numbering (e.g. "3 of 10") automatically calculated
Open package/index.html in a browser and use File → Print → Save as PDF to generate the printable package brochure. All pages are already print-formatted.

What happens if I skip replacing data.json?

The website still shows your changes (because package/index.html is updated). But the next time you open the editor, it loads from browser storage — which has your edits. However, if you ever clear browser storage or open the editor on a new device, it falls back to the data.json on disk, which would be outdated. Always replace both files.

Making changes live on the website (GitHub Pages)

Replace the files on disk as described above.
Open a terminal in the unq-kitchen-site folder.
Run: git add package/index.html menu-editor/data.json
Run: git commit -m "Update packages"
Run: git push — the site updates within a minute.

How to open the editor

Double-click index.html — it opens in your browser directly as a local file. No server or internet required.
The editor loads with the last session's data automatically (saved in browser storage). First-ever open uses the bundled data.
To load a fresh data.json (e.g. after another device exported one), use the Import JSON button in the top-right.
The editor works entirely offline. All edits are saved automatically to your browser's local storage — you never lose work by accidentally closing the tab.

Item Matrix

A full cross-reference of every item in the master menu against all packages. Use it to see what's in what, find gaps, and add or remove items with a single click.

Reading the table

Cell appearanceMeaning
☑ Checked checkboxItem is included in this package
☐ Empty checkboxItem is not in this package
☐ Green-tinted cell + Item not in package but its price is a good fit for the package tier — suggested addition
unassignedItem exists in master menu but is not in any package yet

Adding an item to a package

Tick the checkbox in the cell where the item's row meets the package column. The item is immediately added to the first section of that package. You can then move it to the correct section in the Package Builder tab.

Removing an item from a package

Untick the checkbox. The item is removed from all sections of that package where it appeared.

Filters

  • Search box — filter rows by item name
  • Category dropdown — show only items from one menu category (e.g. Hot Beverages, Snacks)
  • Assignment filter — show All items, Unassigned only, or Assigned to ≥1 package
The matrix is derived entirely from the data — it always reflects what is currently saved. Any change in the Package Builder is instantly visible here too.

Package Builder

The main editing workspace. Three columns: Item Pool on the left, Sections in the middle, and a sidebar on the right.

Package tabs

Each package has its own tab at the top. Click a tab to switch packages. The + New Package button at the end creates a blank package.

Package info strip (top bar)

Edit the package Name, Price, Description, and Ideal For text inline. Changes save automatically.

Left panel — Item Pool

Lists all 237+ master menu items grouped by category.

  • Items already in this package are dimmed with a ✓ mark.
  • Use the search box or category dropdown to find items quickly.
  • Toggle between All Items and In Package to see only what's already been added.

Adding an item — drag from pool

Find the item in the pool panel.
Click and hold, then drag it to the target section's drop zone in the middle panel.
The item appears as a chip in that section. Its display name defaults to the master menu name — click the name to edit it.
The display name (what prints on the package page) is separate from the master menu ref (used for pricing and matrix). For example, the display name can be "Veg Pakoda" while the master ref stays "Pakoda – Mix". The small grey hint below the name shows the master ref when it differs.

Moving items between sections

Drag an item chip from one section and drop it onto another section's drop zone. The item moves instantly.

Removing an item

Either click the × on the chip, or drag the chip down to the "Drop here to remove" zone at the bottom of the pool panel.

Reordering sections

Grab the ⠿ drag handle on the left of a section header and drag it above or below another section.

Editing a section

  • Click the section name to rename it.
  • Edit Instruction (e.g. "Choose any two") and Chip / Qty (e.g. "1 round") in the two fields below the header.
  • Click × on the section header to delete the entire section.

Item badges

Each chip has a small badge field (shown in gold on the printed page — e.g. "Unlimited", "On request"). Click the badge area on the chip to edit or remove it.

Price Analysis

Each item in the package is rated against the package price per person:

  • ✓ ≤20% — item price is well within the package tier
  • ~ 20–35% — borderline, keep an eye on it
  • ⚠ >35% — item may be too expensive for this package tier

For flagged items, swap chips appear showing alternative items from the same menu category that fit the price. Click a swap chip to replace the item instantly.

Terms & Conditions

Each package has its own set of terms and a cancellation policy. Switch packages using the tabs at the top.

Terms bullets

Each bullet is a separate editable text area. Click + Add Term to add a new one, or click × to delete. The text supports HTML (e.g. wrap a word in <strong> for bold on the printed page).

Cancellation policy

Three columns: Condition (e.g. "More than 24 hrs"), Result (e.g. "Full Refund"). Add or remove rows. These appear in the printed cancellation box at the bottom of each package page.

Venue & Services page

This is the last page in the printed document — "Book Your Space". It lists the Indoor Hall, Outdoor Lawn, decoration options, and event types. It has the same section structure as packages but without a price.

Editing

  • Edit the Page Subtitle at the top (currently "Two distinct venues · Fully managed events · Bilaspur").
  • Each venue/category is a Section — rename, edit the detail field (e.g. "600 sq ft"), and the capacity chip (e.g. "Up to 40 guests").
  • Items within each section are the features listed. Add, rename, remove, or add a badge (e.g. "On request", "Extra cost").
  • Use + Add Section to add a new venue or category row.

Design tab

Edit the visual appearance of the printed package pages — colors, fonts, spacing, layout — without touching any content.

CSS editor

The left panel shows the full CSS from template.html. Edit any rule and the live preview on the right updates within a second.

Live preview

The right panel shows a single package page rendered with your current CSS. Use the package selector dropdown to switch which package you're previewing.

Saving design changes

Edit the CSS in the left panel.
Click Save Design. Two things happen: the CSS is saved to browser storage (instant, persists across sessions), and a new template.html file is downloaded.
Replace menu-editor/template.html with the downloaded file. This makes the design change permanent — it will be in the editor next time you open it.
If you only rely on browser storage and clear your browser data, the CSS override is lost. Always replace template.html after important design changes.

Reset button

Discards any local CSS overrides and reloads the CSS from template.html (or the embedded copy if opened as a file). Use this to undo design experiments.

Exporting

Click the Export Package Page button in the top-right. Two files download automatically:

File downloadedWhat to do with it
data.jsonReplace menu-editor/data.json — keeps the source file in sync with your edits.
package-index.htmlRename to index.html and replace package/index.html in the main site folder — this is the live package page.
Always replace both files. data.json is the source of truth; if you only replace the HTML and later export again, you'll start from the old data.

What the export preserves

  • All original CSS and fonts (including the embedded BlippoMN font and print styles)
  • All design changes made in the Design tab
  • Page numbering (automatically updated based on number of packages)
  • The static "Book Your Space" page — now generated from your edits in the Venue tab

Auto-save & data persistence

Every change you make — adding an item, editing a term, reordering a section — is saved to your browser's local storage immediately. You can close the tab and re-open the editor; your work will still be there.

Local storage is browser-specific and device-specific. If you open the editor on a different computer, it will start from the bundled data. To carry your work across devices, export data.json and use Import JSON on the other device.

Importing data from another device

On the source device, click Export Package Page and save data.json.
On the target device, open the editor and click Import JSON (top-right).
Select the data.json file. The editor reloads with all your packages, items, and terms.

Rebuilding the editor

The editor embeds a copy of data.json and template.html inside index.html so it works as a local file. When you update either of those files on disk, the embedded copies inside the editor become stale.

To sync them, run the rebuild script from the unq-kitchen-site folder:

python3 menu-editor/rebuild.py

This regenerates index.html with the latest data.json and template.html embedded inside. Run it any time you:

  • Replace template.html after a Design save
  • Manually edit data.json outside the editor
  • Want to distribute the editor to someone else as a fresh standalone file
For day-to-day use you don't need to rebuild. Local storage always has your latest edits. Rebuild is only needed to update the embedded starting-point data.
